# 🌤️ API-based Weather App

A responsive web application that fetches and displays live weather data using the OpenWeatherMap API. Built for the MERN Full Stack Internship Program (Week 2 Mini Project).

## 🚀 Features
- Search for any city worldwide to get current weather data.
- Displays Temperature (°C), Weather Condition, Humidity, and Wind Speed.
- Custom dynamic weather icons and background themes based on current conditions.
- Smooth loading animations and UI transitions.
- Fully responsive design (Mobile & Desktop friendly).
- Error handling for invalid city inputs.

## 💻 Technologies Used
- **HTML5**: Semantic structure.
- **CSS3**: Custom styling, CSS Variables, Keyframe Animations, and Flexbox layout.
- **JavaScript (ES6+)**: DOM Manipulation, `fetch` API, Async/Await logic.

## 🔌 API Source
- Data provided by [OpenWeatherMap API](https://openweathermap.org/api).
